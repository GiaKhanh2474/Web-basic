# Laptop Store - Website bán laptop

## 1. Giới thiệu
Website bán laptop được xây dựng bằng ngôn ngữ PHP, MySQL, HTML, CSS và JavaScript.

## 2. Công nghệ sử dụng
- PHP
- MySQL
- HTML/CSS
- JavaScript
- XAMPP

## 3. Cài đặt dự án
1. Tải hoặc clone source code từ GitHub.
2. Đưa thư mục Laptop_store vào `htdocs`.
3. Mở phpMyAdmin.
4. Tạo database có tên `laptopstore`.
5. Import file `database/laptopstore.sql`.
6. Sao chép `config/db.example.php` thành `config/db.php`.
7. Cấu hình thông tin kết nối database.
8. Truy cập `http://localhost/Laptop_store/`.

## 4. Chức năng
- Hiển thị danh sách laptop.
- Tìm kiếm và xem chi tiết sản phẩm.
- Quản lý giỏ hàng.
- Kiểm tra số lượng tồn kho.
